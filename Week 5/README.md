# Week 5 - Spark Fundamentals Assignment

This assignment is based on Spark fundamentals and DataFrame operations using PySpark.

## Topics Covered

- Limitations of MapReduce
- Advantages of Spark
- In-memory processing
- Spark DataFrames
- Data cleaning
- Removing duplicates
- Handling null values
- Filtering records
- GroupBy and aggregation
- Shuffle and wide transformations
- Schema casting and column renaming

## Files Included

- spark_assignment_answers.md: Contains answers of Week-5 questions.
- spark_code.py: Contains PySpark code for cleaning, filtering, aggregation and final pipeline.

## Summary

In this assignment, I practiced Spark DataFrame operations. I learned how to remove duplicates, handle null values, filter data, perform aggregations and build a small data processing pipeline using PySpark.
